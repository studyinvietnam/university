## 📚 Giới thiệu

Khóa học **Lập trình Hướng Đối Tượng với Java** cung cấp kiến thức nền tảng về ngôn ngữ lập trình **Java** và kỹ thuật **Lập trình Hướng Đối Tượng (Object-Oriented Programming - OOP)**.

Đây là khóa học phù hợp cho những bạn muốn xây dựng nền tảng lập trình Java vững chắc trước khi tiếp tục với:

- ☕ Java Backend
- 🌐 Java Web
- 📱 Android
- 🗄️ Database
- 🚀 Spring / Spring Boot
- 💼 Phỏng vấn lập trình

Khóa học không chỉ tập trung vào cú pháp Java mà còn giúp người học **rèn luyện tư duy lập trình, thuật toán và kỹ năng giải quyết bài toán** thông qua hệ thống bài tập chấm tự động.

---

## 🎯 Mục tiêu khóa học

Sau khi hoàn thành khóa học, người học có thể:

- Hiểu các kiến thức nền tảng của **Java**
- Nắm vững tư duy **Lập trình Hướng Đối Tượng**
- Làm việc với **Class, Object, Inheritance, Polymorphism...**
- Sử dụng các cấu trúc dữ liệu và kỹ thuật lập trình cơ bản
- Rèn luyện tư duy thuật toán
- Giải quyết các bài toán lập trình thông qua hệ thống chấm tự động
- Có nền tảng để học **Java Web / Java Backend**
- Làm quen với việc kết nối Java với **Cơ sở dữ liệu**
- Tiếp cận **JSP & Servlet**
- Chuẩn bị kiến thức cho các bài phỏng vấn lập trình
