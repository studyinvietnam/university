Hàm bạn (Friend Function)

Xây dựng hàm cộng hai số phức? → Phương thức của lớp
Vấn đề đặt ra
  • Một hàm độc lập không thể truy nhập vào thành phần riêng (private/protected) của lớp.
  • Phương thức của một lớp chỉ truy nhập vào thành phần riêng của chính lớp đó.
  • Câu hỏi: Làm sao để một hàm có thể truy nhập vào các thành phần riêng của nhiều lớp khác nhau?
Giải pháp: Dùng hàm bạn
  • Hàm bạn là một hàm độc lập, không phải phương thức của lớp.
  • Có thể truy nhập vào các thành phần riêng của lớp mà nó được khai báo làm bạn.
class A {
    friend void f(...); // f là bạn của lớp A
};

Gọi hàm bạn cong(ps1, ps2)
• Hàm cong() nhận 2 đối tượng lớp PS làm tham số.
• Là một hàm độc lập (không gọi qua toán tử dấu chấm ps1.cong()).
• Do được khai báo friend trong lớp, hàm có thể truy cập trực tiếp tử số và mẫu số của ps1, ps2.
Các hướng mở rộng (Commented)
• Tái sử dụng các phương thức nhap(), xuat().
• Chuẩn bị cho việc nạp chồng toán tử cộng operator+ và toán tử xuất operator<<.

Ví dụ: Hàm bạn cộng hai số phức

Khai báo Lớp & Hàm bạn C++ Code 
    // cộng hai số phức là hàm friend
    class SP {
        double a; // Phần thực
        double b; // Phần ảo
    public:
        friend SP cong(SP u1, SP u2);
    };

    SP cong(SP u1, SP u2) {
        SP u;
        u.a = u1.a + u2.a;
        u.b = u1.b + u2.b;
        return u;
    }
Sử dụng trong main()
    int main() {
        SP u, u1, u2;
        // ...
        u = cong(u1, u2);
        // ...
    }
Phân tích điểm chính
• Từ khóa friend cho phép hàm cong() truy cập trực tiếp các thuộc tính riêng tư a (thực) và b (ảo) của tham số u1, u2.
• Định nghĩa hàm cong() bên ngoài không cần dùng toán tử phạm vi SP::.

So sánh: Hàm thông thường vs. Hàm bạn

1. Hàm phương thức (Dùng Getter/Setter) Phương thức 
PS tong(PS ps1, PS ps2) {
        PS t;
        t.setTS(ps1.getTS() * ps2.getMS() + ps1.getMS() * ps2.getTS());
        t.setMS(ps1.getMS() * ps2.getMS());
        return t;
    }
• Bắt buộc dùng các hàm trung gian getTS(), getMS(), setTS(), setMS().
• Cú pháp dài dòng, tốn chi phí gọi hàm.
2. Dùng Hàm Bạn (Friend Function) Hàm bạn 
// ham ban
    PS cong(PS ps1, PS ps2) {
        PS t;
        t.ts = ps1.ts * ps2.ms + ps1.ms * ps2.ts;
        t.ms = ps1.ms * ps2.ms;
        return t;
    }
• Truy cập trực tiếp các thuộc tính ẩn ts (tử số) và ms (mẫu số).
• Code ngắn gọn, trực quan, tốc độ thực thi tối ưu hơn.

Ví dụ: Hàm là bạn của nhiều lớp

Khai báo & Cài đặt C++ Code 
    #include <iostream>
    using namespace std;

    class B; // Forward declaration

    class A {
        float X;
    public:
        A() { X = 5.0; }
        friend float Init(A, B);
    };

    class B {
        float Y;
    public:
        B() { Y = 1.0; }
        friend float Init(A, B);
    };

    float Init(A a, B b) {
        return a.X + b.Y;
    }
Hàm main() 
    int main() {
        A a;
        B b;
        cout << Init(a, b);
    }
Kết quả & Lưu ý
• Kết quả in ra: 6 (5.0 + 1.0).
• Forward Declaration: Khai báo trước class B; là bắt buộc để lớp A biết đến kiểu dữ liệu B khi khai báo hàm bạn.
• Hàm Init() có quyền truy cập trực tiếp các thành phần private (X của A và Y của B).

So sánh cách gọi: Hàm bạn vs. Phương thức của lớp

Hàm main() minh họa C++ Code 
    int main() {
        PS ps1(5, 7);
        PS ps2(4, 8);

        PS t = cong(ps1, ps2);      // ham ban
        PS t2 = ps1.tong(ps2);    // phuong thuc

        t.xuat();

        // ps1.xuat();
        // ps2.nhap();
        // cout << ps2; // ps2.xuat();
        // PS t = ps1 + ps2;
    }
1. Hàm bạn: cong(ps1, ps2)
• Đóng vai trò là một hàm độc lập.
• Gọi trực tiếp bằng tên hàm và truyền đầy đủ 2 đối tượng ps1, ps2 làm tham số.
• Cú pháp thể hiện sự đối xứng rõ ràng giữa 2 toán hạng.
2. Phương thức: ps1.tong(ps2)
• Là thành viên (member function) thuộc về lớp.
• Được gọi thông qua đối tượng ps1 nhờ toán tử dấu chấm (.).
• Phải truyền thêm đối tượng còn lại ps2 vào danh sách tham số.

Nạp chồng toán tử (Overloading Operator)

Cài đặt toán tử cộng bằng Phương thức C++ Code 
    // chong toan tu
    PS operator +(PS ps) {
        PS t;
        t.ts = this->ts * ps.ms + this->ms * ps.ts;
        t.ms = this->ms * ps.ms;
        return t;
    }
Sử dụng con trỏ this
• Con trỏ this trỏ tới đối tượng ở vế trái của phép cộng (ví dụ: ps1 trong ps1 + ps2).
• Tham số truyền vào ps tương ứng với đối tượng ở vế phải (ví dụ: ps2).
Cách gọi tương đương trong main()
• Sử dụng cú pháp tự nhiên: PS t = ps1 + ps2;
• Trình biên dịch sẽ hiểu ngầm thành lời gọi phương thức: PS t = ps1.operator+(ps2);

Nạp chồng toán tử đảo ngược (!) cho Phân số

Cách 1: Đảo ngược trực tiếp void operator! 
    // chong toan tu ! la dao nguoc PS
    void operator ! () {
        int t = ts;
        ts = ms;
        ms = t;
    }
• Tác động: Thay đổi trực tiếp giá trị tử số (ts) và mẫu số (ms) của chính đối tượng hiện tại.
• Sử dụng: !ps1; (không trả về giá trị).
Cách 2: Trả về Phân số mới PS operator! 
    PS operator ! () {
        PS t;
        t.ts = ms;
        t.ms = ts;
        return t;
    }
• Tác động: Tạo và trả về một phân số mới là nghịch đảo của đối tượng hiện tại (đối tượng cũ giữ nguyên).
• Sử dụng: PS p2 = !ps1;

Hàm toán tử là phương thức của lớp

Đặc điểm của Hàm toán tử
  • Con trỏ this đóng vai trò là đối ẩn thể hiện cho toán hạng thứ nhất (vế trái).
  • Phương thức toán tử một ngôi: Không nhận tham số đầu vào (ví dụ: operator!()).
  • Phương thức toán tử hai ngôi: Chỉ nhận duy nhất 1 đối số (ví dụ: operator+(PS ps)).
Hạn chế của phương thức toán tử
• Không xử lý được khi hai toán hạng thuộc hai lớp khác nhau (hoặc toán hạng vế trái không thuộc về lớp đang định nghĩa).
PS p;
cout << p; // Báo lỗi!
Giải thích: Do vế trái là cout (thuộc lớp ostream), không thể định nghĩa phương thức toán tử << trong lớp PS.

Định nghĩa toán tử vào/ra (>> / <<)

[Nhắc lại] Khái niệm cơ bản
  • Mục đích sử dụng: Khi muốn thực hiện nhập/xuất dữ liệu cho một lớp theo cách đơn giản, tự nhiên như với các kiểu dữ liệu cơ bản (cin >> x;, cout << x;).
  • Bản chất toán tử:
    • Là toán tử hai ngôi.
    • Hai toán hạng thuộc hai kiểu khác nhau (stream và đối tượng).
  • Giải pháp: Cần phải định nghĩa như là hàm bạn (friend function) của lớp.
Ví dụ áp dụng
Xây dựng lớp Đa thức (DT), trong đó có định nghĩa các toán tử:
  • >> : Toán tử nhập đa thức từ luồng vào (istream).
  • << : Toán tử xuất đa thức ra luồng ra (ostream).
  • = : Toán tử gán đa thức.

Cài đặt toán tử nhập (>>) bằng hàm bạn

1. Phương thức nhập (Member Function) void nhap() 
    // Phương thức
    void nhap() {
        cout << "\nNhap phan so: ";
        cin >> ts >> ms;
    }
• Bắt buộc gọi thông qua đối tượng: ps.nhap();
• Không hỗ trợ nhập liên tiếp nhiều đối tượng trên cùng một dòng lệnh.
2. Nạp chồng toán tử nhập (Friend Function) operator>> 
    // chong toan tu
    friend istream& operator >>(istream &is, PS &ps) {
        cout << "\nNhap phan so: ";
        is >> ps.ts >> ps.ms;
        return is;
    }
• Cho phép viết tự nhiên: cin >> ps;
• Trả về istream& để hỗ trợ chuỗi nhập liên tiếp: cin >> a >> b;
• Cần khai báo friend để truy cập trực tiếp thuộc tính private ts, ms.

Cài đặt toán tử xuất (<<) bằng hàm bạn

1. Phương thức xuất (Member Function) void xuat() 
    void xuat() {
        cout << endl << ts << "/" << ms;
    }
• Bắt buộc gọi thông qua đối tượng: ps.xuat();
• Không thể viết chuỗi xuất liên tiếp (ví dụ: cout << ps1 << ps2;).
2. Nạp chồng toán tử xuất (Friend Function) operator<< 
    friend ostream& operator <<(ostream &os, PS ps) {
        os << endl << ps.ts << "/" << ps.ms;
        return os;
    }
• Cho phép viết tự nhiên: cout << ps;
• Trả về ostream& để hỗ trợ chuỗi xuất liên tiếp: cout << a << b;
• Cần khai báo friend để truy cập trực tiếp thuộc tính private ts, ms.

Bảng so sánh: Hàm bạn vs. Phương thức của lớp

Hàm bạn (Friend Function) Phương thức của lớp (Member Function)
Có thể được khai báo là bạn trong bất kỳ số lượng lớp nào bằng từ khóa friend. Chỉ có thể được khai báo trong phạm vi private, public hoặc protected của một lớp cụ thể.
Có thể truy cập tất cả các thành phần private và protected của (các) lớp khai báo nó là bạn. Chỉ có thể truy cập các thành phần private và protected của chính lớp đó.
Có thể gọi trong hàm main() mà không cần tạo đối tượng. Phải tạo một đối tượng của lớp để gọi phương thức.
Sử dụng từ khóa friend để khai báo. Không cần từ khóa đặc biệt khi khai báo.
Được gọi như một hàm thông thường, định nghĩa bên ngoài lớp. Có nguyên mẫu (prototype) trong định nghĩa lớp, thao tác trên đối tượng của lớp.
Thường dùng để truy cập/sửa đổi dữ liệu private/protected giữa nhiều lớp. Thường dùng để cải thiện tính tái sử dụng và bảo trì mã nguồn.
Toán tử hai ngôi nhận 2 tham số tường minh (vế trái và vế phải). Toán tử hai ngôi chỉ nhận 1 tham số tường minh (vế phải, vế trái là this).
Toán tử một ngôi nhận ít nhất 1 tham số tường minh. Toán tử một ngôi không nhận tham số tường minh.
Không phải là thành phần của lớp. Là thành phần của lớp và được gọi thông qua đối tượng cụ thể.
