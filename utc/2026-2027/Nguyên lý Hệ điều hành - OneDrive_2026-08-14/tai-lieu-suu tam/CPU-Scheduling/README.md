**Q. What is CPU scheduling? full explaination.**
➡️ **Hỏi:** Định tuyến CPU là gì? giải thích đầy đủ.

**Ans -> CPU Scheduling is a fundamental operating system function that decides, which processes or programs get to run on the CPU and in what order.**
➡️ **Trả lời ->** Định tuyến CPU là một chức năng hệ điều hành cơ bản quyết định, tiến trình hoặc chương trình nào được chạy trên CPU và theo thứ tự nào.

**Note:– It helps to manage the execution of multiple tasks on a computer.**
➡️ **Lưu ý:–** Nó giúp quản lý việc thực thi nhiều tác vụ trên một máy tính.
