A = [3, 7, 2, 9, 5]

Max ← A[0]
for i ← 1 to n-1 do
    if A[i] > Max then
        Max ← A[i]
return Max
Output: Max = 9

▪ Độ phức tạp không gian (Space Complexity)
Đánh giá lượng bộ nhớ thuật toán cần sử dụng để lưu: dữ liệu đầu vào, các biến, dữ liệu trung gian, kết quả đầu ra.
Ví dụ minh họa (Bubble Sort) 
for (int i = 0; i < n - 1; i++) {
    for (int j = n - 1; j > i; j--) {
        if (A[j] < A[j - 1]) {
            int tg = A[j];
            A[j] = A[j - 1];
            A[j - 1] = tg;
        }
    }
}
Mảng dữ liệu
A[n] chứa toàn bộ dữ liệu cần sắp xếp.
Biến điều khiển
n, i, j dùng để biết kích thước mảng và điều khiển vòng lặp.
Biến tạm
tg giữ tạm một giá trị khi đổi chỗ hai phần tử.
Cần tính: A[n] + n + i + j + tg

KÍCH THƯỚC ĐẦU VÀO VÀ THỜI GIAN CHẠY

  • Kích thước đầu vào (thường ký hiệu là \(n\)): cho biết quy mô của dữ liệu mà thuật toán phải xử lý.
  • VD: cho mảng
    A = [3, 7, 2, 9, 5]
    Mảng có 5 phần tử \(\Rightarrow n = 5\)
  • Thời gian chạy (thường ký hiệu \(T(n)\)): lượng thời gian hoặc lượng công việc mà thuật toán cần để xử lý dữ liệu đầu vào.
Max ← A[0]
for i ← 1 to n-1 do
    if A[i] > Max then
        Max ← A[i]
return Max
→
So sánh \(n - 1\) lần
→
\(n \uparrow \Rightarrow T(n) \uparrow\)

TỐC ĐỘ TĂNG TRƯỞNG (GROWTH RATE)

  • Tốc độ tăng trưởng (growth rate): cách mô tả hàm thời gian \(T(n)\) tăng nhanh đến mức nào khi kích thước đầu vào \(n\) tăng
  • Các dạng tăng trưởng gồm: \(1, \log n, n, n \log n, n^2, n^3, 2^n\)
  • Ký hiệu dùng để biểu diễn tốc độ tăng trưởng: Big-O
Ví dụ:
\(T(n) = 7n - 2\)
\(O(n)\)
\(T(n) = 3n^2 + 20n + 5\)
\(O(n^2)\)

int arrayMax(int A[], int n) {
    int max = A[0];
    for (int i = 1; i < n; i++) {
        if (A[i] > max) {
            max = A[i];
        }
    }
    return max;
}

KHÁI NIỆM VỀ ĐỆ QUY

\[ n! = \begin{cases} 1, & \text{nếu } n = 0 \\ n \times (n-1)!, & \text{nếu } n \ge 1 \end{cases}, \quad n \in \mathbb{N}. \]
Giai thừa biến bài toán lớn thành bài toán nhỏ hơn, cho đến trường hợp cơ sở \(0! = 1\)

ĐỆ QUY: HAI THÀNH PHẦN BẮT BUỘC

Một định nghĩa đệ quy chỉ có ý nghĩa, khi thỏa mãn đồng thời hai điều kiện:
• Trường hợp cơ sở (Base case):
Là trường hợp nhỏ nhất có thể giải trực tiếp mà không cần tiếp tục đệ quy.
VD: 0! = 1
• Bước đệ quy (Recursive step):
Các trường hợp còn lại phải được đưa về một trường hợp nhỏ hơn
VD: n! = n × (n - 1)!
(quá trình thu nhỏ phải đạt tới trường hợp cơ sở sau hữu hạn bước)
