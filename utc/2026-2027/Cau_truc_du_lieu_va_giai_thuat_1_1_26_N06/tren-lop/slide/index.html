1. Ngôn ngữ tự nhiên Mô tả
Bước 1: Nhập a, b.
Bước 2: Nếu a ≠ 0 thì tính x = -b/a.
Bước 3: Nếu a = 0 và b = 0 thì phương trình có vô số nghiệm.
Bước 4: Nếu a = 0 và b ≠ 0 thì phương trình vô nghiệm.
Bước 5: Kết thúc.

3. Mã giả (Pseudocode) Pseudocode 
Algorithm GiaiPT(a, b)

        Input: a, b
        Output: nghiệm ax + b = 0

        if a ≠ 0 then
            x ← -b / a
            Output x

        else if b = 0 then
            Output "Vô số nghiệm"

        else
            Output "Vô nghiệm"
Gần với ngôn ngữ lập trình
4. Ngôn ngữ lập trình C++ C++ 
#include <iostream>

    using namespace std;

    int main() {

        float a, b;

        cin >> a >> b;

        if (a != 0)
            cout << -b / a;

        else if (b == 0)
            cout << "Vo so nghiem";

        else
            cout << "Vo nghiem";

        return 0;
    }

int main() {
    double a, b;

THUẬT TOÁN (Algorithm)

▪ Ví dụ thuật toán: tìm phần tử lớn nhất
A = [3, 7, 2, 9, 5]
Diễn giải từng bước
▸ Ban đầu: Max = 3.
▸ So sánh 7 với 3 → cập nhật Max = 7.
▸ So sánh 2 với 7 → giữ nguyên.
▸ So sánh 9 với 7 → cập nhật Max = 9.
▸ So sánh 5 với 9 → giữ nguyên.
Mã giả (Pseudocode) Algorithm 
Max ← A[0]
for i ← 1 to n-1 do
    if A[i] > Max then
        Max ← A[i]
return Max
Output: Max = 9

CÁC KHÍA CẠNH CẦN PHÂN TÍCH

▪ Độ phức tạp không gian (Space Complexity)
Đánh giá lượng bộ nhớ thuật toán cần sử dụng để lưu: dữ liệu đầu vào, các biến, dữ liệu trung gian, kết quả đầu ra.
Ví dụ minh họa (Bubble Sort) 
for (int i = 0; i < n - 1; i++) {
    for (int j = n - 1; j > i; j--) {
        if (A[j] < A[j - 1]) {
            int tg = A[j];
            A[j] = A[j - 1];
            A[j - 1] = tg;
        }
    }
}
Mảng dữ liệu
A[n] chứa toàn bộ dữ liệu cần sắp xếp.
Biến điều khiển
n, i, j dùng để biết kích thước mảng và điều khiển vòng lặp.
Biến tạm
tg giữ tạm một giá trị khi đổi chỗ hai phần tử.
Cần tính: A[n] + n + i + j + tg
