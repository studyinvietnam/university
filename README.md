# 📚 Tài liệu học Đại học — Hùng Anh

> Kho lưu trữ tài liệu, bài tập, source code và những thứ mình học được trong hành trình Đại học.  
> Chủ yếu là **Khoa học máy tính — UTC K66** 💻

---

## 👨‍🎓 Giới thiệu

Xin chào, mình là **Hùng Anh**.

Hiện tại mình đang theo học:

- 🏫 **Trường Đại học Giao thông Vận tải (UTC)**
- 📍 Cơ sở Cầu Giấy, Hà Nội
- 💻 **Ngành: Khoa học máy tính**
- 🎓 **Khóa: K66**
- 📅 Bắt đầu học Đại học từ **2025**

Repository này được tạo để lưu lại quá trình học tập của mình trong những năm Đại học.

Không phải project xịn sò gì đâu 😭  
Đây chủ yếu là nơi mình:

> **Học → Code → Sai → Debug → Hiểu → Lưu lại → Quên → Mở repo ra xem lại** 💀
